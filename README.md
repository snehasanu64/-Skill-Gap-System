**Skill Gap System** is a modern, intelligent career planning platform designed to help professionals and students bridge the gap between their current skill set and their dream job. By analyzing industry requirements against user input, it generates a personalized learning roadmap with specific milestones and resources.

---

## ✨ Key Features

*   **🎯 Smart Gap Analysis**: Instantly compare your skills against 50+ professional job roles (MERN, Data Science, DevOps, UI/UX, etc.).
*   **🗺️ Dynamic Roadmaps**: Get a step-by-step learning path including recommended technologies, timelines, and difficulty levels.
*   **📊 User Dashboard**: Track your saved analyses and monitor your progress as you acquire new skills.
*   **🛡️ Admin Management**: Robust dashboard for managing job roles, required skill sets, and system configurations.
*   **💎 Premium UI/UX**: Built with a sleek, modern dark-mode aesthetic featuring glassmorphism and smooth micro-animations.

---

## 🛠️ Tech Stack

*   **Backend**: PHP 8.x
*   **Database**: MySQL (PDO for security)
*   **Frontend**: HTML5, CSS3 (Vanilla + Modern CSS Variables), JavaScript (ES6+)
*   **Icons/Fonts**: Outfit & Inter (Google Fonts), Lucide-style emojis

## 🚀 Quick Setup

To run this project locally using WAMP, XAMPP, or MAMP:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/skill_gap_analyzer.git
    ```

2.  **Database Configuration**:
    *   Open your PHPMyAdmin.
    *   Create a new database named `skill_gap_db`.
    *   Import the `database.sql` file provided in the root directory.

3.  **Configure the App**:
    *   Open `config.php` and update your database credentials if different from the default (root/no password).

4.  **Run the App**:
    *   Move the folder to your `www` (WAMP) or `htdocs` (XAMPP) directory.
    *   Access it via `http://localhost/skill_gap_analyzer`.

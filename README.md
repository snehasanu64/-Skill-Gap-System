# 🎯 Skill Gap Analyzer
 
A PHP/MySQL web platform that compares your current skills against industry job requirements
and generates a personalised learning path to help you close the gap.
 
## ✨ Features
 
- Input your skills and select a target job role
- Automatically identifies missing skills
- Shows a clear gap analysis
- Suggests learning resources and roadmap
- Progress tracking over time

## ⚙️ Run Locally (WAMP/XAMPP)
 
```bash
git clone https://github.com/snehasanu64/-Skill-Gap-System.git
```
 
1. Copy folder to `C:/wamp64/www/`
2. Import `.sql` file in phpMyAdmin
3. Visit `http://localhost/-Skill-Gap-System`
## 📋 Requirements
 
- WAMP or XAMPP
- PHP 7+
- MySQL
